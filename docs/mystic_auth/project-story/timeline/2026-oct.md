# How It Evolved: October 2026

---

### Commit 78: 1 October, 2026

- Standardized the canonical MysticAuth brand color across schemas, setup tooling, frontend branding, favicon tests, and generated environment defaults.
- Added non-interactive PowerShell setup support and a Windows CI regression job.
- Raised frontend coverage gates to 90% for every metric, stabilized Vitest workers, and documented browser-owned coverage boundaries.
- Added unit coverage for shared shadcn components, font-size state, security-log details, routing, and existing UI behavior.
- Added Bash, PowerShell, and Windows CMD scripts to run the backend outside Docker, deriving database and Valkey URLs from configured host ports without editing environment files.
- Added port-derivation tests, Make targets, and documentation for running the backend outside Docker with multi-project port configurations.
- Removed the refresh redirect, keyed raw email addresses in application logs, isolated databases on an internal network, and tightened container capabilities and backup-sidecar identity.
- Added regression coverage for refresh routing, log redaction, condition schemas, rate-limit edge cases, Valkey failures, sessions, and shared frontend behavior.
- Moved `DEFAULT_APP_POLICIES` behind the app-owned settings extension point and added environment-parity, integration, and live-smoke coverage for the template boundary.
- Hardened upstream sync deletion and relocation handling, with explicit paths and regression coverage for stale-file removal.
- Reworked backup and restore execution around least privilege, explicit network handling, round-trip verification, and network-isolation tests.
- Reorganized environment templates so frequently changed settings appear first, documented the optional security-alert webhook configuration and payload.
